# A Shakti Rao – Portfolio

React + Vite + Tailwind CSS + Framer Motion + Lucide icons, with dark/light mode.

## Run
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

## Customise
- Links (email, GitHub, LinkedIn, project URLs): `src/data.js`
- Content (skills, projects, education): `src/data.js`
- Colors/fonts: `tailwind.config.js` and the Tailwind classes in `src/components/`

## Deploy
Push to GitHub and import the repo in Vercel or Netlify (build: `npm run build`, output: `dist`).
